# Lab 7: Bikewatching

For Lab 7, I made an interactive map of Bluebikes traffic in Boston and Cambridge using trip data from March 2024. I added bike lanes and used circles to show activity at each station. The size of each circle shows how busy the station is, and the color shows whether it has more arrivals or departures.

I added a time slider so I could see how station traffic changes throughout the day. Hovering over a station shows the exact number of arrivals and departures.
